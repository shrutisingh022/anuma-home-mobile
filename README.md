# Anuma home · mobile

The mobile ad landing page for anuma.co.in. One page.

- **Layout, order and every word:** `anuma-home-mobile-v2.html` (6 Nov), unchanged. Its CSS is `app/base.css`.
- **Visual language:** the live anuma.co.in (source: `anuma-site/wireframe`), applied in `app/live.css`:
  ink on warm paper, one hairline card shell, IBM Plex Sans, the black liquid "Start chat" pill,
  frosted glass, Morse dot stages, gradient step orbs, marigold highlight. No serif, per Neil.

## Run

```bash
npm install
npm run dev   # http://localhost:3310 (on your phone: http://<your-mac-ip>:3310)
```
